# 中文开头与音色一致性排查 · 2026-10-03

用户报告不同文本听起来像不同人，语调和中文读字不标准，尤其开头。当前版本不能视为稳定可用音色；之前仅凭短句运行成功不足以验证质量。

## 已复现

使用用户原文“夜幕低垂，城市的霓虹灯接连亮起……”全文，0.6B Base、同一参考录音、相同随机种子42。所有实验不训练、不修改基础权重、不使用此前否定的 B LoRA。

1. 原服务：仅说话人特征，采样0.9，默认模拟文字流。开头自动转录为 `Yorumoku Tichu`，随后“霓虹灯”“汇聚”“光河”也出现误识，与用户报告相符。
2. 完整日语参考音频+转录，相同采样：开头识别为“也莫期待此 行屍的泥骨灯”，没有可靠改善。
3. 仅说话人特征，整段文字预先输入：开头识别为“有把柯迪茨”，仍失败。
4. 完整日语参考，整段文字预先输入：自动转录未识别第一整句，从“在这个……世界上”开始。需要试听区分错读、不可识别或实际漏读；不能只凭 ASR 断言音频没有第一句。

另测关闭两级随机采样：两句短文本中多次输出20.4秒，达到256 token对应的长度附近，疑似退化或重复，未采用。该组6段原始 WAV 保存在 consistency-20261003-203542；其自动转录遇到本地 PyAV 接口兼容问题，未完成。随后脚本改用 soundfile 读取及16kHz重采样，后两组自动转录均成功。

## 证据与限制

- 两组全文结果：`data/LocalTTS/windows/outputs/consistency-20261003-203851/` 和 `consistency-20261003-204132/`，含WAV、开头1.5秒片段、参数、自动转录和试听页。
- 自动转录能筛查明显错读，不能证明标准声调、音色相似度或自然度。没有把任何实验标为质量通过。
- 参考来自 `yachiyo_070.wav`，通过自动日语识别置信度选取，未人工审核。small/medium 两个识别器的参考转录一致，也不能代替人工确认。
- 原服务已固定随机种子并缓存同一文本；这不保证不同文本音色相同。
- 官方说明 `x_vector_only_mode=True` 仅使用说话人嵌入，可能降低克隆质量：https://github.com/QwenLM/Qwen3-TTS#voice-clone 。本机完整参考提示实验也失败，因此不能宣称此开关就是修复。

## 当前决定

未将失败实验替换到8773默认服务。该服务仅为实验试听，不应作为游戏正式播报或中文训练数据来源。所有用户原始素材保留。

下一阶段先人工选定一段干净、单人、语气平稳且确实符合目标音色的参考录音，核对逐字转录；优先验证有对应准确文本的中文目标音色参考。若只有日语参考，跨语言克隆是否能达到要求仍需验证。不要用当前错读合成音频自我训练。

若校对参考后仍不能稳定读中文，再比较“标准中文TTS生成发音→音色转换”的独立路线；目前未实现、未下载新模型，也未承诺能满足实时或保留目标音色。

复现脚本：`tools/windows_voice/voice_consistency.py --text "测试文本"`；增加 `--whole-text` 对比整段文字预先输入。使用现有 Windows 语音虚拟环境运行。
