# Windows 持久语音缓存

voice_config.example.json 默认启用 `cache_dir: ../../data/VoiceCache/windows-api`，目录相对于配置文件。设置 null 可关闭磁盘缓存，内存缓存保持原行为。缓存目录已由现有 Git 规则忽略。

服务启动时对模型文件和参考录音的实际内容计算 SHA-256，并加入生成参数、参考文本、推理依赖版本和缓存格式版本。修改这些内容并重启后会使用独立缓存，旧文件保留。端口变更不改变音色缓存。首次启动要读取模型文件计算摘要，耗时依磁盘速度而定。

同一句台词重启后可从磁盘读取，X-Cache 为 hit；未命中时生成并保存。损坏缓存按未命中处理。保存使用同目录临时文件和原子替换，不能写缓存时仍返回本次生成的音频。

disk_cache_mib 默认512，限制此缓存根目录内所有版本JSON文件总量；到达上限后停止写入新条目，不删除旧音频。缓存以JSON封装WAV及生成指标，体积比WAV稍大。仅支持一个服务进程使用同一缓存目录；容量检查不是跨进程配额锁。

缓存不改善发音，可能保留有问题的实验输出。更换参考录音和参数后会隔离旧版本；不要把缓存当作合格训练数据。当前仍需模型正常加载后才能调用缓存，本轮没有增加无模型离线播放器。

尚未批量预生成整个剧本；普通游戏播报会逐条填充缓存。停止播放的GPU取消限制保持不变。
