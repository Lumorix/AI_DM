# Windows 游戏语音播报

1. 按 tools/windows_voice/VOICE-API.md 启动本机语音服务（默认127.0.0.1:8775）。
2. 按项目原有 start.bat 启动游戏；若游戏之前已启动，需要重启才能加载新增路由。
3. 在主持电脑浏览器打开游戏 /screen，刷新页面，选择“八千代（本机实验）”，点击开启语音朗读。

可选择浏览器声音或八千代。开场和阶段旁白、公开DM回答进入同一播放队列；当前默认仍是浏览器声音。八千代的中文发音和音色一致性尚未通过质量验证。

“停止本段”会清空播放队列并忽略当前旁白后续文字的语音；文字仍正常显示。“跳过当前句”继续队列下一句。切换阶段、切换声音、关闭朗读或离开页面均会清理当前音频。

取消会中止浏览器请求、丢弃过期结果和释放音频资源，但不会强行中断已经提交到GPU的模型计算；下一句在服务忙碌时最多等待约120轮后提示错误。生成失败会清空当前队列并显示原因，不偷偷切换另一种声音。浏览器若阻止自动播放，页面会提示重新开启朗读。

语音代理 /api/voice/health 和 /api/voice/speech 仅接受主持电脑本机请求。手机不能使用此实验接口；常规玩家功能不受影响。更改语音端口时，除更改语音JSON配置外，还要在启动游戏前设置环境变量 AIDM_VOICE_PORT。代理目标固定127.0.0.1，不接受网页传入任意服务器地址。

当前按句等待整段WAV后播放，不是真正流式音频；无句号的长文本按120字符分段可能影响韵律。示例配置已启用磁盘缓存，重启后可复用，详见 CACHE.md；尚未提供整个剧本的批量预生成。

发生生成或播放错误时，朗读开关会回到“关”，后续文字不会反复触发失败请求。处理服务或设备问题后可直接点击重新开启。

验证：Python会话与语音代理测试、JavaScript重连与队列测试。播放器测试使用模拟Audio/fetch；仍需在实际Edge/Chrome中试听确认设备输出和自动播放权限。
