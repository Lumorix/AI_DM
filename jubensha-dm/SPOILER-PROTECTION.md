# 防剧透修复记录

2026-10-04，本地 Harry 分支。

## 已改行为

- Python 与 Swift 的旁白/复盘先在内存中收集完整模型输出，通过当前阶段禁用词检查后，才向大屏、玩家和朗读模块发送正文。跨分片禁用词不会在检查前播出。
- 模型输出命中时检查原文回退；原文也命中则整段不播，只给主持人提醒。原文模式、AI 暂停模式、生成错误、开局直接写入记录均走检查。
- 生成取消或阶段变化时丢弃未审核内容，不写入公开历史。Swift 换阶段也取消原旁白任务。
- Python 旁白不附 dm_notes；两版公开问题不附提问角色 secret_brief。私聊仍可使用本人秘密摘要。
- Python 支持 `词@阶段id` 和 `dm.forbidden_until`，与 Swift 使用相同解禁时点：从目标阶段起解除，之后继续解除；回退到更早阶段时重新生效。
- 不带目标的词默认在首次 reveal 解禁；没有 reveal 则持续锁定。无效全局目标提醒并保持锁定；无效的 `词@阶段id` 配置在两版加载校验中报错，避免静默失效。

```yaml
dm:
  forbidden_until: final
  forbidden:
    - "第一层秘密@early"
    - "最终秘密"
```

`early` 和 `final` 必须是现有阶段 id，文本必须按实际需要配置。不需要因为新增字段重建已有存档。

## 体验变化与边界

旁白首句需要等待整段生成，不能再提前播放未经检查的模型片段。已有语音队列和缓存仍可处理审核后的文本。本次没有重训声音或改语音模型。

这是规范化关键词检查，不是完整语义泄露检测；同义改写、暗示和未列入禁用词的秘密仍可能漏过。原文/公开摘要/简介也需审查，问答仍有全局真相与主持提示。公开玩家输入和手动发放的线索没有在此任务中改成内容审核。

已经存在于存档的公开历史不会自动重写或清除；回退阶段也不会撤回已经公开的信息。要验证新拦截效果，请使用测试新局或新的旁白请求，保留原存档。
