# Mac 问答时序保护

2026-10-04，Harry 分支。接续防剧透修复，补齐 Swift 问答在等待模型期间的状态校验。

- 玩家提问绑定阶段编号、阶段开始时间、角色设备 token。模型返回、重试及发布前均检查；角色释放、换手机、阶段变化、同阶段重新进入或请求取消后，旧回答不能显示、朗读或发线索。
- 主持台公开提问绑定阶段编号和开始时间；错误回退也不能越过时序校验。
- 最终发线索再次检查本阶段 grantable、线索存在、玩家未持有且未公开。
- 返回无效时释放 busy 状态；原提问记录保留，旧回答不会写入历史。仍在等待的请求保留忙碌状态，直到模型返回/请求结束，不强行启动重复请求。
- 新增 GameLanguageModel 接口以注入可控制完成时机的测试模型；实际应用继续使用原 LLM 实现，不修改服务地址或模型配置。

新增 10 项 Swift XCTest：跨阶段、同阶段重入、设备重新认领、释放角色、取消、过期错误回退、主持台问答、已公开/已持有线索、正常回答发放。

在 Mac 的 `jubensha-dm` 目录执行：

```bash
swift test --filter AnswerConsistencyTests
./build.sh
```
